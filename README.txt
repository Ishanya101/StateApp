STATE — Personal State Tracker

EASIEST WAY TO USE ON IPHONE:
1. Download the ZIP and extract it on a computer.
2. Put the folder on any static web host (GitHub Pages, Netlify, Vercel, etc.).
3. Open the resulting website in Safari on your iPhone.
4. Tap Share -> Add to Home Screen.
5. Open State from your home screen.

IMPORTANT:
- Data is stored locally in the browser/device.
- Export your data periodically as a backup.
- This is a self-tracking tool, not a medical diagnostic tool.
